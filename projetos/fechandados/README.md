# Fechando com Dados

**Fechando com Dados** é uma série de projetos curtos de Ciência de Dados construída a partir de **dados públicos recentes**.

A proposta é simples: pegar uma base real, formular uma pergunta clara, fazer uma análise objetiva e fechar cada projeto com uma conclusão útil, defensável e comunicável.

Mais do que estudar ferramentas de forma isolada, a ideia é usar dados para entender temas do mundo real e transformar esse processo em:

- prática
- portfólio
- conteúdo para LinkedIn
- evolução analítica

---

## Ideia da série

Cada episódio da série segue uma lógica simples:

> **dados públicos + pergunta real + análise clara + conclusão fechada**

O foco não é criar projetos gigantescos logo de início, mas sim construir análises enxutas, bem organizadas e com valor prático.

A série foi pensada para unir quatro frentes ao mesmo tempo:

1. **estudo aplicado**
2. **criação de portfólio**
3. **treino de comunicação com dados**
4. **produção de conteúdo baseado em evidências**

---

## Objetivo

O objetivo do projeto **Fechando com Dados** é transformar bases públicas em pequenos estudos de dados com começo, meio e fim.

Cada episódio busca responder a uma pergunta específica a partir de uma base confiável e recente, gerando um material que possa ser usado tanto para aprendizado quanto para apresentação profissional.

---

## Estrutura de cada episódio

Cada projeto da série pode seguir este fluxo:

1. definição do tema
2. formulação da pergunta principal
3. coleta dos dados
4. inspeção e limpeza
5. análise exploratória
6. visualização dos resultados
7. interpretação
8. conclusão
9. adaptação para portfólio e LinkedIn

---

## Fontes de dados

A série prioriza bases que sejam:

- públicas
- confiáveis
- recentes
- relevantes para temas do mundo real
- acessíveis para análise com Python

Exemplos de fontes que podem ser utilizadas:

- **IBGE**
- **SIDRA**
- **Banco Central**
- **dados.gov.br**
- **Ipea**
- outras bases abertas de interesse público

---

## Ferramentas utilizadas

Os projetos da série podem utilizar, entre outras:

- **Python**
- **Pandas**
- **Matplotlib**
- **Jupyter Notebook**
- **APIs públicas**
- **CSV / XLSX / JSON**
